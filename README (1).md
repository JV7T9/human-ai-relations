# Human-AI Relations: Mapping the Structural Stack

A thesis arguing that modern AI rests on a layered structural infrastructure that had
to crystallise before the systems themselves could appear, and an interactive 3D
visualisation of that stack.

**Live page:** https://jv7t9.github.io/human-ai-relations/

## What is in the thesis

The preconditions that converged, how they formed a layered stack, the degrees of
freedom within it, how older methods are retained while layers mutate, how influence
is translated across layers, the conditions that would weaken the model, and the
implications.

## The interactive panel

The widget is an **illustrative structural model, not empirical telemetry**. Its
sliders (Infrastructure, Cross-Layer Influence, Agent Autonomy, Mutation Pressure,
Speed) and layer toggles show how the argument's ideas could behave. They are not
measured values. Drag to rotate, use the enlarge button for a full-screen view.

## Running it locally

It is a single static file. Open `index.html` in a browser. No build step is needed.
The page loads its fonts and visualisation libraries over the network.

## Built with

Three.js, React and Radix UI for the visualisation. The thesis and visualisation were
developed with assistance from several AI systems (Microsoft Copilot, Claude, Grok and
OpenAI language models), as described in the page's acknowledgements.
